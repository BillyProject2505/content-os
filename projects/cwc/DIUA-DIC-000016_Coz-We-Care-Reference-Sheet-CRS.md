## 2. CRS Scope & Terminology

CRS is the CWC Reference Sheet documentation/container layer. It is not the name of the logo or of any single asset. Each asset is named independently below.

**CRS Asset Identifier Rule — OWNER DECISION:** `CWC-CRS-AS-###` is the CRS-domain record identifier for an asset. It identifies the CRS record/decision scope for the asset as a whole and is independent of the existence of `_REF-##` child references. `_REF-##` is an optional child identifier used only for individually-addressable reference artifacts.

**Resolved 2026-09-06:** REF-level visual reference assets for Asset 002 that previously contained an internal on-image label "ASSET ID" were regenerated with the label "REF ID"; the Owner reviewed and accepted the regenerated images.
